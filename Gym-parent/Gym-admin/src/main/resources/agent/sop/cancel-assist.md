# 取消预约协助处理说明

适用场景：用户提到取消预约、退款，或正在处理一条待确认的取消草稿。

## 处理步骤

1. 先区分意图：
   - 用户在问取消/退款规则 → 使用知识检索工具查证据后回答，并标注引用。
   - 用户明确要求取消 → 进入办理流程。
2. 办理时先查询当前用户本人可取消的预约列表，列出预约ID和关键信息。
3. 参数不够（没有预约ID）时追问用户要取消哪一条；不要替用户选择。
4. 拿到预约ID后调用取消草稿工具生成草稿；草稿内容以工具返回为准，是否产生退款申请以工具说明为准。
5. 草稿生成后告知用户需要确认；确认命令与确认码来自后端草稿，不要自己生成。
6. 用户回复“取消”表示放弃当前草稿时，由后端确认流程处理。

## 边界

- 只能查询本人预约、生成取消草稿，不能直接取消。
- 退款是否到账以业务结果为准，不要声称已退款。
- 用户的预约数据只能来自本人查询工具，不要假设预约ID。
